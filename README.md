📌 About the Project

SKP Official Portfolio is a personal portfolio website designed to establish my professional online presence and showcase my technical capabilities.

The website features a modern user interface, smooth animations, interactive components, customizable themes, and a functional contact form.

It is designed to provide recruiters, developers, and potential collaborators with an easy way to explore my profile and connect with me.

---

✨ Features

- Responsive Design – Compatible with desktop, tablet, and mobile devices.
- Modern UI/UX – Clean, attractive, and professional interface.
- Dark & Light Mode – Switch between different website themes.
- Custom Color Picker – Personalize the website accent color.
- Loading Animation – Smooth loading screen experience.
- Mobile Navigation – Interactive hamburger menu and sidebar.
- Smooth Scrolling – Seamless navigation between sections.
- Active Navigation – Automatically highlights the current section.
- Scroll Reveal Animations – Animated elements while scrolling.
- Skills Filtering – Filter technical skills by category.
- Projects Showcase – Display projects with descriptions and links.
- Interactive Contact Form – Visitors can send messages directly.
- Web3Forms Integration – Handles contact form submissions.
- SweetAlert2 Notifications – Attractive success and error popups.
- Dynamic Visitor Greeting – Displays the visitor's entered name after successful form submission.
- Character Counter – Displays the message character count.
- Local Storage – Saves theme and accent color preferences.
- Social Media Integration – Connect through professional platforms.

🚀 Getting Started

Follow these steps to run the portfolio locally.

1. Clone the Repository

git clone https://github.com/sachinpandey7709/NEW-SKP-OFFICIAL.git

2. Navigate to the Project Directory

cd NEW-SKP-OFFICIAL

3. Open the Project

Open "index.html" in your preferred web browser.

Alternatively, use the Live Server extension in Visual Studio Code.

---

⚙️ Configuration

Contact Form Setup

This portfolio uses Web3Forms to process contact form submissions.

To configure the contact form:

1. Visit "Web3Forms" (https://web3forms.com/).
2. Create an account.
3. Generate your Access Key.
4. Add the Access Key to the contact form's hidden input field.
5. Test the form by submitting a message.

Theme Customization

The website supports customizable accent colors and dark/light themes.

Theme preferences and selected accent colors are stored using browser LocalStorage.
